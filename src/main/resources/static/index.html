Fan-Out & Idempotency Guarantee

When you submit an event with (X-Tenant-Id, event_id_external):

  • Atomic Fan-Out: The event is saved and fanned out to all matching active subscriber endpoints into pending deliveries.
  • Strict Idempotency: Duplicate event IDs return the original event without generating duplicate webhook dispatches.
  • HMAC Signature: Outgoing HTTP requests carry X-Webhook-Signature (SHA-256) and X-Webhook-Timestamp.
